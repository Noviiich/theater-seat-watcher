# theater_tickets

Telegram-бот отслеживает новые сеансы Орловского театра «Свободное пространство»,
подбирает соседние места и в дальнейшем будет отправлять ссылку на оплату.
Полное описание проекта находится в [docs/README.md](docs/README.md).

На текущем шаге создан только безопасный каркас приложения. Он не выполняет
сетевых запросов и не создаёт заказы. Режим по умолчанию — `dry_run`.

## Требования

- Python 3.12 или новее
- [uv](https://docs.astral.sh/uv/)

## Установка и проверка

```bash
uv sync --all-groups
uv run python -m theater_tickets
uv run ruff check .
uv run ruff format --check .
uv run mypy src
uv run pytest
```

Для будущих настроек скопируйте `.env.example` в `.env` и задайте значения вне
Git. Пока `.env` не загружается автоматически, а статус CLI не показывает секреты.

Не включайте `BOOKING_MODE=live`, пока не завершён исследовательский шаг checkout
из [roadmap](docs/roadmap.md). Даже будущий live-режим не должен автоматически
оплачивать билеты: оплату совершает пользователь на стороне продавца.
