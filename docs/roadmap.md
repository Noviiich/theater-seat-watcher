# Roadmap по отдельным коммитам

Каждый пункт — один самостоятельный логический commit с результатом и проверкой.
Названия коммитов предложены заранее; выполненные изменения ещё не закоммичены.
Отметка `[x]` означает наличие результата в файлах, а не наличие Git-коммита.
В исходной рабочей папке при исследовании Git-репозитория не было; инициализация
репозитория и первый commit относятся к отдельному началу разработки.

Стратегия: проверить оформление рано → создать read-only основу → подобрать места
→ добавить безопасное оформление и восстановление → подключить автоматический
сценарий → развернуть. Никакой этап не делает изменяющие запросы по умолчанию.
