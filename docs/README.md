# Документация theater_tickets

Документация обновлена 17 сентября 2026 года. Исследование публичных страниц
и запросов чтения QuickTickets выполнено 16 сентября. Код приложения пока не написан.

Уточнение пользователя: удержание действует **3 минуты**. Для каждого нового
подходящего сеанса бот оформляет первый заказ сразу, а затем повторяет подбор
и оформление после истечения неоплаченной брони, присылая новую ссылку каждые
180 секунд при доступных удобных соседних местах. Оплата, остановка или окончание
отслеживания завершают цикл; предыдущая бронь должна быть проверена перед новой.

Читать в порядке: требования → исследование → архитектура → алгоритм → roadmap.

Главная техническая неопределённость: получение переносимой ссылки на оплату
после подтверждённого удержания мест. Чтение схемы и занятости проверено,
изменяющие запросы и реальная оплата в рамках исследования не выполнялись.
Три минуты — сведения пользователя; точку начала отсчёта и способ подтверждения
окончательного истечения без оплаты ещё нужно закрепить в контракте checkout.
