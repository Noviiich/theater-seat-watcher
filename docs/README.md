# Документация theater_tickets

Документация обновлена 17 сентября 2026 года. Исследование публичных страниц
и запросов чтения QuickTickets выполнено 16 сентября. Базовый пакет, чистый
домен, durable discovery и локальное планирование лимитов уже созданы; live
adapter пока не реализован.

Уточнение пользователя: оплата удержанного заказа доступна **20 минут**. Для каждого нового
подходящего сеанса бот оформляет первый заказ сразу, а затем повторяет подбор
и оформление через 1200 секунд, присылая новую ссылку при доступных удобных
соседних местах. Оплата не завершает цикл автоматически; это делает `/stop`,
пауза или окончание отслеживания. Статус предыдущей оплаты не запрашивается.

Читать в порядке: требования → исследование → архитектура → алгоритм → roadmap.

Главная техническая неопределённость: получение переносимой ссылки на оплату
после подтверждённого удержания мест. Исследовательский `initAnytickets` уже
подтверждён как изменяющий запрос: он создаёт временное удержание. Реальная
оплата не выполнялась. Три минуты — сведения пользователя; точку начала отсчёта
и способ подтверждения окончательного истечения без оплаты ещё нужно закрепить
в контракте checkout.
